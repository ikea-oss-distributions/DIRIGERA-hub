To Download the LFS files for version 99.99.999 please follow the instructions

1. Clone the repository by running following command on terminal `git clone https://github.com/ikea-oss-distributions/DIRIGERA-hub-v99.99.999`
2. Change directory `cd DIRIGERA-hub-v99.99.999`
3. Initialize LFS: `git lfs install`
4. Download the LFS files: `git lfs fetch --all`
