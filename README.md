To Download the LFS files for version .4.0 please follow the instructions

1. Clone the repository by running following command on terminal `git clone https://github.com/ikea-oss-distributions/DIRIGERA-hub-v.4.0`
2. Change directory `cd DIRIGERA-hub-v.4.0`
3. Initialize LFS: `git lfs install`
4. Download the LFS files: `git lfs fetch --all`
